Trainingsplan-App aufs Handy bringen

Wichtig: Die Datei index.html direkt vom Handy-Speicher zu öffnen funktioniert NICHT
(der Browser blockiert dann das Laden der 3D-Modelle im Ordner figur/).
Der ganze Ordner muss über eine Web-Adresse (https) erreichbar sein.

Einfachster Weg (kostenlos, ca. 2 Minuten):
1. ZIP auf dem Computer entpacken.
2. https://app.netlify.com/drop öffnen und den ENTPACKTEN Ordner (nicht die ZIP) hineinziehen.
3. Netlify gibt eine Adresse aus (https://....netlify.app). Diese auf dem Handy öffnen.
4. Im Browser: Menü > "Zum Startbildschirm hinzufügen" (Android/Chrome) bzw.
   Teilen > "Zum Home-Bildschirm" (iPhone/Safari). Danach startet die App im Vollbild.

Alternative: GitHub Pages (Ordner in ein Repository legen, Pages aktivieren).

Nötig sind: index.html, figur/ (4 Dateien, ca. 24 MB), manifest.webmanifest, icon.svg.
Beim Laden braucht das Handy Internet (Rechen-Bibliotheken kommen von cdn.jsdelivr.net).
